chut. personne ne connaît cette page. voir le site ↗

chaque carte est une photo. toutes apparaissent sur la page « toutes les photos » (triables par catégorie) ; celles cochées « clichés favoris » s'affichent en plus sur l'accueil, avec la taille choisie. tout ce que tu tapes est enregistré automatiquement (dans ce navigateur).

ici, ce sont les phrases du site lui-même : accueil, bio, contact… les petites phrases de chaque photo, elles, se modifient dans l'onglet « les photos », directement sur la carte de la photo concernée. laisse un champ tel quel pour garder le texte d'origine. un retour à la ligne = un saut de ligne sur le site. une ligne entre (parenthèses) devient une nuance en couleur.

tes réglages vivent dans ce navigateur. pour qu'ils soient visibles par tout le monde, il faut mettre à jour les fichiers du site :

  1. télécharge les deux fichiers ci-dessous ;
  2. remplace js/photos-data.js et js/site-config.js dans le dossier du site ;
  3. si tu as choisi des photos « fichier », copie les vrais fichiers dans un dossier photos/ et indique leur chemin dans l'onglet photos.
